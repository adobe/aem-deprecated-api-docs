## Libraries

If you are using any of the below 3rd party libraries, preferably update to the latest version - at least to the version mentioned in the table.

| Library / Component | Maven coordinates | Minimum Version |
|---|---|---|
| ACS AEM Commons | `com.adobe.acs:acs-aem-commons-bundle` | **6.17.2** |
| io.wcm AEM Mock (JUnit5) | `io.wcm:io.wcm.testing.aem-mock.junit5` | **5.6.14** |
| Adobe Commerce CIF Core Components | `com.adobe.commerce.cif:core-cif-components-core` | **2.18.0**; also update magento-graphql |
| Adobe Commerce Magento GraphQL | `com.adobe.commerce.cif:magento-graphql` | **11.2.2** |
| Adobe I/O Events OSGi lib | `com.adobe.aio.aem:aio-lib-osgi` | **2.0.12** |
| Adobe I/O Events for AEM | `com.adobe.aio.aem:aio-aem-events` | **2.0.2** |
| Adobe AEM Assetshare | `com.adobe.aem.commons.assetshare.core` | **3.16.6** |
| io.wcm CAConfig Extensions | `io.wcm:io.wcm.caconfig.extensions` | **1.9.6** |
